
# 🌸 Flower Shop Website

A modern, responsive flower shop website built with React and JavaScript. This project showcases a floral boutique's products, services, and brand through an elegant and user-friendly web experience.

## 📖 About the Project

The Flower Shop Website is a frontend web development project designed to establish an online presence for a floral boutique. It features a clean, visually appealing layout that allows visitors to explore flower arrangements, browse collections, discover services, and learn more about the business.

The project focuses on responsive UI design, reusable React components, and an intuitive browsing experience.

## ✨ Features

- **Homepage** – Introduces the floral boutique and highlights featured content.
- **Flower Collections** – Displays available flowers and arrangements.
- **Product Details** – Provides additional information about selected flower arrangements.
- **Services** – Showcases the shop's floral services.
- **Gallery** – Presents floral designs and visual inspiration.
- **About Page** – Shares the shop's story and brand identity.
- **Location & Visit** – Provides information for customers planning to visit.
- **Reservation Page (prototype)** – Offers a dedicated page for reservation-related inquiries.
- **WhatsApp Integration (prototype)** – Provides a convenient way for customers to contact the shop about purchases.
- **Reusable Components** – Uses reusable React components to maintain consistent UI elements.
- **Responsive Design** – Designed to provide a smooth browsing experience across different screen sizes.

## 🛠️ Built With

- **React** – Component-based UI development.
- **JavaScript** – Application logic and interactivity.
- **Vite** – Development server and build tooling.
- **CSS** – Styling and layout.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/s3e0o/flower-shop-react.git
   ```

2. Navigate to the project directory:

   ```bash
   cd flower-shop-react
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the website.

### Production Build

To create a production-ready build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
